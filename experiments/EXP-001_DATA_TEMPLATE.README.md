# EXP-001 data template

This CSV is intentionally empty. Populate it only from an authorized historical-data export. Do not replace missing SKEW observations with synthetic values or proxies without a separately approved change to the preregistered experiment.

Keep the raw/licensed source outside the repository when redistribution rights do not permit committing it. Ingest through `app.experiment_001_csv.py`, record the manifest/fingerprint, and preserve the source and SKEW methodology versions.
