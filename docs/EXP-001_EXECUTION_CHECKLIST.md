# EXP-001 Execution Checklist

Before empirical execution, confirm:

- [ ] Historical SPX, VIX, and SKEW data came from an authorized export or licensed feed.
- [ ] Original acquisition metadata is preserved.
- [ ] Every row has source, version, methodology version, and content provenance.
- [ ] Observation and availability timestamps are timezone-aware.
- [ ] No duplicate normalized observation timestamps exist.
- [ ] No point-in-time violation exists.
- [ ] Dataset content hash and manifest are recorded.
- [ ] The preregistered EXP-001 specification is unchanged.
- [ ] No synthetic fixture is presented as empirical evidence.
- [ ] Results are reviewed by the Skeptic/Contrarian layer.
- [ ] Human authority remains required for any consequential decision.
