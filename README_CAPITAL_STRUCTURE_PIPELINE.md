# AletheiaTelos Capital Structure Pipeline Integration

Capital Structure Intelligence is analytical context inside the existing institutional intelligence pipeline. It is not a parallel financing decision system.

## Pipeline

```text
validated financing evidence
        -> capital structure analysis
        -> Computational Kaleidoscope
        -> independent perspectives
        -> Conflict / Coexistence
        -> Independent Risk Simulation
        -> Contrarian Review
        -> Investment Case
        -> Decision Readiness
        -> Decision Gate
        -> Human Investment Authority
        -> Decision Record
```

The existing evidence boundary remains authoritative. Capital-structure context is attached to the existing research context so the existing AgentRunner and perspective interfaces can consume it without creating a financing-specific agent.

## Epistemic separation

Capital-structure values retain their origin:

- **observed**: supported by validated evidence and linked to evidence IDs
- **derived**: calculated from explicit inputs and retaining source evidence IDs
- **assumed**: explicitly introduced for scenario or sensitivity analysis
- **unknown**: not established by available evidence

An observed financing term is never inferred from another term. For example, an observed LTV does not create an interest rate, maturity, amortization schedule, covenant package, or refinancing assumption.

## Risk integration

The existing independent Monte Carlo engine remains the risk engine. Capital-structure context and explicit financing assumptions are carried as analytical context; they do not silently alter simulation mathematics. A future scenario calculation may consume an explicitly supported financing variable without creating a second financing simulator.

The existing scenario taxonomy remains unchanged. No scenario is treated as a prediction.

## Conflict and contrarian review

Existing independent perspectives receive the same analytical context. Their conclusions remain independent until the existing Conflict Intelligence stage. Financing disagreements can therefore remain `CONFLICT` or `COEXISTENCE` according to existing semantics. Contrarian Review can challenge financing assumptions or missing evidence without converting a challenge into fact.

## Investment Case and readiness

Capital-structure analysis is preserved in the existing Investment Case as analytical information. It does not automatically create a case, readiness, approval, or decision record. Material financing uncertainty can remain visible to Decision Readiness according to its existing rules.

## Governance boundary

Capital Structure Intelligence cannot:

- approve financing
- commit financing
- select or rank lenders
- solicit financing
- originate loans
- authorize investments
- execute transactions
- transfer capital
- mutate portfolios
- grant authority to providers or AI

Decision Gate remains the authorization boundary. Human Investment Authority remains the sole investment authorization authority.

## Provider independence

Provider identity is preserved as provenance only. The same analytical pathway can represent private lenders, banks, family offices, institutional debt providers, equity providers, strategic capital providers, and future providers. Provider representation does not imply partnership, endorsement, financing commitment, commercial relationship, or data-sharing agreement.

## Auditability

The integrated context preserves scenario IDs, source evidence IDs, epistemic classification, explicit assumptions, unknowns, and pairwise comparisons. The pipeline also records the capital-structure analytical context in the existing research/audit projections.

The constitutional principle remains:

> AletheiaTelos exists to help humans see more clearly. It does not make the consequential decision for them.
