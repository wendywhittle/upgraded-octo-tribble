# Registered Roster

The `/simulate` orchestration path now calls the formal Computational Kaleidoscope registry rather than constructing agent dictionaries directly.

With no verified evidence supplied to that route, registered perspectives return `NO_DATA`. This prevents synthetic demo assumptions from being mistaken for decision-usable evidence.

Verified external research and market observations can enter through the existing read-only evidence boundaries. A future model-backed agent provider can then consume that evidence through the same contract.
