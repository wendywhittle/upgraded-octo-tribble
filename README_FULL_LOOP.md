# AletheiaTelos Full Decision-Intelligence Loop

The evidence-fed analysis path is now explicitly ordered:

`Evidence -> Integrity -> Computational Kaleidoscope -> Conflict Analysis -> Independent Monte Carlo -> Skeptic -> Synthesis -> Governance -> Observer -> Epistemic Memory`

The `/analysis/run` endpoint consumes evidence supplied to the system; it does not fetch external information. Evidence that fails the integrity gate never reaches the perspectives. The Monte Carlo engine remains independent of agent conclusions and receives only audit assumptions. Skeptic review occurs after simulation, before synthesis. Governance requires human decision authority and exposes no brokerage or execution capability.

The existing `/simulate` endpoint remains a no-evidence demonstration and therefore returns `NO_DATA` through the formal agent contract rather than fabricating decision-usable evidence.
