# AletheiaTelos Full Decision-Intelligence Loop

The evidence-fed analysis path is explicitly ordered:

`Evidence -> Integrity -> Computational Kaleidoscope -> Conflict Analysis -> Independent Monte Carlo -> Skeptic -> Synthesis -> Governance -> Observer -> Epistemic Memory`

`POST /analysis/run` consumes evidence supplied to the system; it does not fetch external information. Evidence that fails the integrity gate never reaches the perspectives. Monte Carlo remains independent of agent conclusions and receives assumptions only as audit metadata. Skeptic review occurs after simulation and before synthesis. Governance requires human decision authority and exposes no brokerage, order, credential, or portfolio-mutation capability.

The existing `/simulate` endpoint remains a no-evidence demonstration and therefore returns `NO_DATA` through the formal agent contract rather than fabricating decision-usable evidence.
